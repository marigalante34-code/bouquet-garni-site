# Bouquet Garni · site

Site-portfólio publicado em https://bouquetgarnisp.com.br (GitHub Pages).

- `index.html` — página única.
- `img/` — fotos (JPEG, até ~1100 px).
- Para incluir fotos no portfólio: coloque o arquivo em `img/` e adicione uma linha na lista `FOTOS` no fim do `index.html` (`["arquivo-sem-extensao","Legenda","salgados|doces|bebidas"]`).
